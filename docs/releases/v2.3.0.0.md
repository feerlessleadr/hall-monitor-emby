## Hall Monitor plugin 2.3.0.0

"Reduce time" can now take away more than the extra time that was added. Install over 2.2.0.0; nothing in your settings changes. The Embidextrous app 0.10.0 uses this for its new "-30 min" button, so update the plugin first, then the app.

### What's new
- **Take time away from the limit itself.** Before, Reduce (the Undo of extra time) could only take back time that had been added, and did nothing for a child with no extra time. Now it lowers the allowance below the limit, down to nothing. Example: a child with 3 minutes left on a 3 minute limit, reduced by 3 minutes, has an allowance of 0 and is blocked. The time never reads as negative, and a reset (or the next period) puts everything back to normal.
- **The status says so.** `ApiLevel` is 5. An app that sees 5 knows Reduce can go below the limit; with an older plugin it only takes back extra time.
- A limit whose allowance is zero or less reports 100% used (it is used up), never "no limit".

### Checked
- 23 unit tests (2 new); the regression suite on a test server passed 71 of 71 (one check changed on purpose: Reduce used to stop at zero extra time).
- Live, with the Embidextrous app on an emulator and a throw-away child with a 3 minute daily limit: "-30 min" with 29 minutes 45 seconds left took exactly 30 minutes and left 0; after a fresh day, "-30 min" took exactly the 3 minutes that were left, the child was blocked, and the allowance was 0 (not negative).

### Known limits
- A weekly or monthly limit was not tried live (unit tested).
- The plugin's own dashboard page does not show the per-limit list or a taken-away allowance specially.
