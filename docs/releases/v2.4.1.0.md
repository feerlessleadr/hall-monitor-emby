## Hall Monitor plugin 2.4.1.0

A fix for the first seconds after a server restart. Install over 2.4.0.0; nothing in your settings changes.

### What's fixed
- **No old totals after a restart.** The plugin used to load the watch time saved from the last session and apply a reset that came due while the server was off only on its first timer tick, 15 seconds later. For those seconds the status (and the pushed status the Embidextrous app listens to) showed yesterday's usage, so the phone could say a child had used 93% of their daily time while the dashboard showed 0. Due resets are now applied as the plugin starts, before any status is served.

### Checked
- The plugin builds and the 26 unit tests pass.

### Known limits
- Not tried on a live server restart with a saved total from the day before.
