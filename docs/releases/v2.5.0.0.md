## Hall Monitor plugin 2.5.0.0

The status now says why extra time was added or taken away, so the Embidextrous app can put the reason in its notification. Install over 2.4.0.0; nothing in your settings changes, and callers that send nothing extra (older apps, older Home Assistant automations) keep working.

### What's new
- **`Source` and `Reason` on time changes.** `POST /HallMonitor/Public/ExtendTime` and `/Public/ReduceTime` accept two optional text fields next to `UserId` and `Minutes`: `Source` (`app`, `plugin` or `homeassistant`; anything else is stored as `other`, nothing as `unknown`) and `Reason` (a short text such as `Feed Chloe`, one line, at most 80 characters). The admin routes (`/HallMonitor/ExtendTime`, `/ReduceTime`, used by the plugin page) accept `Reason` and always record the source as `plugin`.
- **`RecentTimeChanges` in the status.** Each limited user's status lists their latest 20 changes, oldest first: `Id` (always growing, also across restarts), `AtUtc`, `Minutes` (negative when time was taken away), `Kind` (`Added` or `Removed`), `Source`, `Reason`. It is kept in memory only, so it is empty after a restart. `ApiLevel` is 7.

### Checked
